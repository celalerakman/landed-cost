# Landed Cost

Compare supplier quotations including freight and minimum orders.

Quantity, unit price, freight and minimum order determine the delivered total. Values use Decimal; negative and non-finite inputs are rejected.

## Run

Python 3.11 or newer; no external packages.

```sh
python main.py
python -m unittest discover -s tests -v
```

The module exposes its calculation as an importable function and includes a runnable example.
